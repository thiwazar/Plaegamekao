v1.1 แก้จุดค้างช่วงเปิดเรื่อง

ปรับข้อความไทยช่วงเปิดเรื่องและบทพูดโดยรักษาตำแหน่งข้อความเดิม ผู้ใช้ยืนยันว่าผ่านจุดค้างและคุยต่อได้ใน Azahar แล้ว ชุด Luma ยังเป็นรุ่นทดลองและยังไม่ได้ทดสอบบนเครื่อง 3DS จริง

รายละเอียดชุดแจก v1.1

  • เกมที่รองรับ: The Alliance Alive (USA) รหัส CTR-P-AL4E / Title ID 00040000001CCD00 รุ่น 0
  • ทางเลือกติดตั้ง: แพตช์ไฟล์ .3ds ต้นฉบับในเบราว์เซอร์สำหรับ Azahar หรือสร้าง ZIP Luma สำหรับเครื่อง 3DS ดัดแปลง
  • ขอบเขตการแจก: เว็บให้ดาวน์โหลดเฉพาะข้อมูลแพตช์และชุด Luma ไม่มีรอมต้นฉบับ รอมที่แพตช์แล้ว เซฟ หรือไฟล์ BPS ให้โหลดโดยตรง
  • สถานะ: ผู้ใช้ยืนยันชุดม็อด v1.1 ผ่านจุดค้างช่วงเปิดเรื่องและบทพูดถัดไปใน Azahar; รอมที่แพตช์ผ่านเว็บ เครื่อง 3DS จริง และการเล่นจนจบยังไม่ได้ทดสอบ

ชุด Luma v1.1 สำหรับเครื่อง 3DS ดัดแปลง · รุ่นทดลอง

แพตช์ภาษาไทย v1.1 สำหรับเกมรหัส 00040000001CCD00 รุ่น 0 มีคำแปลและฟอนต์ไทย ชุดนี้สร้างไฟล์ติดตั้ง Luma ผ่านหน้าเว็บ โดยไม่มีเกมหรือเซฟอยู่ในไฟล์ ยังไม่ได้ยืนยันผลบนเครื่องจริง กรุณาสำรองชุดเดิมเพื่อย้อนกลับหากพบปัญหา

ดาวน์โหลดชุด Luma


  1. สำรองม็อดและเซฟก่อนติดตั้ง
  2. แตก ZIP แล้วคัดลอกโฟลเดอร์ luma ไปที่ราก SD ของเครื่อง
  3. ตรวจว่าไฟล์อยู่ที่ SD:/luma/titles/00040000001CCD00/romfs และ SD:/luma/titles/00040000001CCD00/code.ips
  4. กด SELECT ขณะเปิดเครื่อง แล้วเปิด Enable game patching ใน Luma3DS
