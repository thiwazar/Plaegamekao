เมื่อท้องฟ้าถูกปกคลุมด้วยฝนไม่รู้จบ และมนุษย์อยู่ใต้การปกครองของปีศาจ กาลิลกับอาซูราจึงออกเดินทางเพื่อค้นหาโลกที่แท้จริง ระหว่างทางพวกเขาจะพบมิตรต่างเผ่าพันธุ์และความลับที่อาจเปลี่ยนชะตาของทุกอาณาจักร

รายละเอียดชุดแจก v1.0

  • เกมที่รองรับ: The Alliance Alive (USA) รหัส CTR-P-AL4E / Title ID 00040000001CCD00 รุ่น 0
  • ทางเลือกติดตั้ง: แพตช์ไฟล์ .3ds ต้นฉบับในเบราว์เซอร์สำหรับ Azahar หรือสร้าง ZIP Luma สำหรับเครื่อง 3DS ดัดแปลง
  • ขอบเขตการแจก: เว็บให้ดาวน์โหลดเฉพาะข้อมูลแพตช์และชุด Luma ไม่มีรอมต้นฉบับ รอมที่แพตช์แล้ว เซฟ หรือไฟล์ BPS ให้โหลดโดยตรง
  • สถานะ: รุ่นทดสอบ ทดสอบม็อดใน Azahar ช่วงต้นและเมนูไอเทมแล้ว ยังไม่ยืนยันรอมเว็บบนเครื่องเล่นหรือเล่นจนจบ

ดูขนาดและ SHA-256 ของไฟล์ .3ds ที่รองรับและผลลัพธ์

ชุด Luma สำหรับเครื่อง 3DS ดัดแปลง

แพตช์ภาษาไทย v1.0 สำหรับเกมรหัส 00040000001CCD00 รุ่น 0 มีคำแปลและฟอนต์ไทย ชุดนี้สร้างไฟล์ติดตั้ง Luma ผ่านหน้าเว็บ โดยไม่มีเกมหรือเซฟอยู่ในไฟล์

ดาวน์โหลดชุด Luma


  1. สำรองม็อดและเซฟก่อนติดตั้ง
  2. แตก ZIP แล้วคัดลอกโฟลเดอร์ luma ไปที่ราก SD ของเครื่อง
  3. ตรวจว่าไฟล์อยู่ที่ SD:/luma/titles/00040000001CCD00/romfs และ SD:/luma/titles/00040000001CCD00/code.ips
  4. กด SELECT ขณะเปิดเครื่อง แล้วเปิด Enable game patching ใน Luma3DS


แพตช์ .3ds บนเว็บ
ใช้ The Alliance Alive (USA) ฉบับถอดรหัส ขนาด 2,147,483,648 ไบต์ (SHA-256: BCBA12046D2A52D48C2EFACB5EEEB9F8CF834CF8FE9617CD9724EC28BCDF1A44) ระบบตรวจไฟล์ต้นฉบับก่อนแพตช์และตรวจผลลัพธ์ก่อนเปิดดาวน์โหลด ไฟล์เกมประมวลผลบนอุปกรณ์ของคุณ
ดาวน์โหลด .3ds ภาษาไทย
ถ้าใช้ไฟล์ .3ds ที่แพตช์แล้วใน Azahar ให้ปิดม็อด Luma/LayeredFS เดิมของเกมนี้ก่อนเพื่อไม่ให้แพตช์ซ้อนกัน
