การใช้แพตช์
1. เปิดหน้าเว็บผ่าน HTTPS แล้วเลือก Dissidia 012
2. เลือกไฟล์ ISO ต้นฉบับที่มีอยู่ ระบบจะตรวจ SHA-256 และใช้แพตช์ให้ตรงกับรุ่น
3. รอจนตรวจผลลัพธ์เสร็จและดาวน์โหลด ISO ที่ได้
ไฟล์ต้นฉบับจะไม่ถูกเขียนทับหรือส่งขึ้นเซิร์ฟเวอร์ แนะนำคอมพิวเตอร์ Chrome/Edge และพื้นที่ว่างอย่างน้อย 2 GB

มีไฟล์ xdelta แยกในโฟลเดอร์ patches สำหรับทั้งสามฐาน เพื่อใช้งานด้วยโปรแกรม xdelta3 ได้เช่นกัน รูปแบบคำสั่ง:
xdelta3 -d -s "ไฟล์ต้นฉบับ.iso" "ไฟล์แพตช์.xdelta" "Dissidia_012_Thai_v4_TEST.iso"

ไฟล์แพตช์และ README นี้มี SHA-256 บันทึกใน SHA256SUMS.txt ทั้งที่โฟลเดอร์รากและ patches/

ขอบเขตการทดสอบ
แพตช์ทั้งสามผ่านการทดสอบด้วยตัวถอด VCDIFF ที่หน้าเว็บใช้จริง โดยถอด ISO ครบทุกหน้าต่างและได้ขนาด/SHA-256 ของ v4 ตามที่ระบุข้างต้น
ยังต้องทดสอบการดาวน์โหลดผ่าน GitHub Pages หลังเผยแพร่ และเล่นเกมบน PSP/PSP Go จริง จึงคงคำว่า TEST ไว้
การอัปเดตนี้เพิ่มหรือแก้ไฟล์เฉพาะ Dissidia เท่านั้น ไม่มีการลบหรือเปลี่ยนไฟล์เกมอื่น

ตัวอ่านบนเว็บรองรับ default VCDIFF code table โดยไม่มี secondary compression หรือ VCD_TARGET dictionary แพตช์ทั้งสามถูกสร้างให้ตรงเงื่อนไขนี้และมี checksum รายหน้าต่าง
