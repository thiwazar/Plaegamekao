ชุดอัปเดตแพตช์ออนไลน์ Dissidia 012 สำหรับเว็บ Plaegamekao
เว็บเดิม: https://thiwazar.github.io/Plaegamekao/

สถานะ: จัดทำชุดไฟล์พร้อมอัปโหลดแล้ว ยังไม่ได้เผยแพร่ขึ้น GitHub จริง เนื่องจากเซสชันที่เข้าถึงได้ยังไม่ได้ลงชื่อเข้าใช้ GitHub

ติดตั้งบนเว็บเดิม
1. แตก Plaegamekao_Online_FontFix_Update.zip
2. ไปที่ https://github.com/thiwazar/Plaegamekao แล้วเลือก Add file > Upload files
3. อัปโหลดไฟล์ที่แตกไว้ โดยวาง index.html และ fontfix-*.mjs ที่ระดับเดียวกับ index.html เดิม
4. วางไฟล์ใน patches/ และ vendor/ ตามโฟลเดอร์เดิมใน ZIP อย่าเปลี่ยนชื่อหรือย้ายไปไว้โฟลเดอร์ชั้นนอกเพิ่ม
5. Commit changes ลงสาขาที่เว็บเดิมใช้อยู่ (ชุดนี้เตรียมเทียบกับ main)
6. รอ GitHub Pages เผยแพร่เสร็จ แล้วเปิดเว็บเดิมและรีโหลดแบบไม่ใช้แคช (Ctrl+F5)
อย่าอัปโหลด ZIP ทั้งก้อนแทนการแตกไฟล์ และไม่ต้องอัปโหลด ISO ใด ๆ
อย่าลบโฟลเดอร์ covers, แพตช์เกมอื่น หรือ xdelta3-big.js / xdelta3-big.wasm เดิม
การอัปเดตนี้คงรายการเกมอื่น และเปลี่ยนการทำงานเฉพาะ Dissidia เป็นตัวอ่านทีละส่วน

ไฟล์เว็บที่ต้องอัปโหลดครบ
index.html
fontfix-config.mjs
fontfix-ui.mjs
fontfix-worker.mjs
fontfix-vcdiff.mjs
vendor/sha256.umd.min.js
vendor/hash-wasm-LICENSE.txt
patches/FROM_EUR_FULL_UNDUB_TO_Thai_v1.3_PSP_FontFix_TEST.xdelta
patches/FROM_Thai_v1.3_TO_PSP_FontFix_TEST.xdelta
README-ONLINE-TH.txt, WEB-TEST-REPORT.json และ SHA256SUMS.txt เป็นเอกสารประกอบ จะเก็บไว้นอกเว็บก็ได้

การใช้งาน
เลือก Dissidia 012 > เลือก ISO ที่มี > ระบบตรวจไฟล์และเลือกแพตช์ให้ > รอปุ่มดาวน์โหลด ISO
รองรับไฟล์ EUR FULL UNDUB ที่ส่งมา และ ISO ไทย v1.3 ที่ส่งมา โดยตรวจ SHA-256 ไม่ใช่ชื่อไฟล์
หากเลือก ISO ที่แก้ FontFix TEST แล้ว ระบบจะแจ้งว่าไม่ต้องแพตช์ซ้ำ
ไฟล์ขนาด/แฮชไม่ตรงจะถูกปฏิเสธ ไม่มีการเขียนทับต้นฉบับ
ใช้ปุ่มยกเลิกเพื่อเปลี่ยนไฟล์ระหว่างทำงาน
แนะนำ Chrome / Edge รุ่นปัจจุบันบนคอมพิวเตอร์ และมีพื้นที่ดาวน์โหลดว่างอย่างน้อย 2 GB
เปิดหน้าที่แพตช์ไว้จนดาวน์โหลดเสร็จ
ไม่มีการรับประกันการแพตช์ไฟล์ใหญ่บนโทรศัพท์ที่มี RAM น้อย

สิ่งที่แก้จากหน้าเดิม
- หน้าเดิมจอง RAM สำหรับ ISO ต้นทางและปลายทางพร้อมกันเกินขีดจำกัด WASM 3 GB ที่ระบุไว้
- Dissidia ใช้ Web Worker และตัวถอด VCDIFF แบบแยกหน้าต่าง (ไม่ใช่การโหลด ISO ทั้งก้อนเข้า WASM)
- ตรวจ SHA-256 แบบทยอยอ่านสำหรับต้นทาง แพตช์ และผลลัพธ์
- ผลลัพธ์ประกอบจากส่วนของ File เดิมและข้อมูลแก้ไขใหม่ จึงไม่ต้องสำรอง ISO เต็มก้อนใน OPFS
- รวมช่วง COPY ที่ต่อเนื่องกัน เพื่อลดจำนวนชิ้นส่วนไฟล์
- มีปุ่มยกเลิก ป้องกันเริ่มงานซ้อน และคืนทรัพยากรเมื่อเลือกงานใหม่หรือออกจากหน้า
- ไลบรารี hash-wasm 4.12.0 เก็บอยู่ใน vendor บนเว็บเดียวกัน
- ISO ต้นฉบับไม่ถูกส่งขึ้นเซิร์ฟเวอร์ โค้ดแพตช์โหลดเฉพาะแพตช์ขนาดเล็กจากเว็บ

ขอบเขตผลทดสอบ
ดู WEB-TEST-REPORT.json สำหรับผลทดสอบแยกตามสภาพแวดล้อม
ไฟล์จริงทั้งสองต้นทางถูกถอดและประกอบเป็น Blob แล้วตรวจขนาดและ SHA-256 ตรงกับ ISO FontFix
ทดสอบตัวจัดการข้อความของ Web Worker ที่จัดส่งกับ File/Blob ใน Node (ไม่ได้รันเป็นเธรดเบราว์เซอร์ในการทดสอบนี้) และทดสอบตัวอย่างหลายหน้าต่างในเบราว์เซอร์
ทดสอบหน้าเว็บจริงอ่าน ISO ไทย v1.3 จน SHA-256 ผ่านในรุ่นก่อนปรับวิธีประกอบไฟล์ และตรวจการปฏิเสธขนาดผิด/การยกเลิก
ชุดไฟล์ไม่ได้ถูกเผยแพร่หรือทดสอบบน URL GitHub Pages จริงหลังแก้
ยังไม่ได้ทดสอบเกมเต็มบน PSP / PSP Go จริง จึงคงคำว่า FontFix TEST
รายการเกมอื่นถูกคงไว้ แต่ไม่ได้ทดสอบแพตช์เกมอื่นใหม่

ผลลัพธ์ต้องมีขนาด 1751283712 ไบต์ และ SHA-256:
04b201e5bbf718c18a614628b64333d18829888cdb93654ac513e82ad7ef1af7

หมายเหตุสำหรับผู้ดูแล
fontfix-vcdiff.mjs รองรับเฉพาะ default code table, ไม่มี secondary compression และไม่มี VCD_TARGET dictionary
แพตช์ Dissidia สองไฟล์ที่แนบตรงตามเงื่อนไขนี้ และมี checksum ทุกหน้าต่าง
ห้ามนำไฟล์ xdelta รุ่นอื่นมาแทนโดยไม่แก้ค่าตรวจใน fontfix-config.mjs และทดสอบใหม่
เปลี่ยนตัวนำเข้า xdelta3-big.js เดิมเป็น lazy import เพื่อไม่ให้ความผิดพลาดของตัวอ่านเดิมบล็อก Dissidia
