# Radiant Historia: Perfect Chronology ภาษาไทย — Luma v6

เกมที่รองรับ: USA · Title ID `00040000001C8F00`

## ติดตั้งบนเครื่อง 3DS ที่ใช้ Luma3DS
1. แตกไฟล์ `RadiantHistoria_Thai_v6.zip`
2. คัดลอกโฟลเดอร์ `luma` จาก ZIP ไปไว้ที่รากของ SD Card และรวมกับโฟลเดอร์เดิม
3. เปิดเครื่องโดยกดค้าง Select เพื่อเข้า Luma Configuration แล้วเปิด `Enable game patching` จากนั้นกด Start บันทึก
4. เปิดเกมใหม่

## ติดตั้งบน Azahar/Citra
คัดลอกเนื้อหาใน `luma/titles/00040000001C8F00/romfs` ไปที่ `%APPDATA%\Azahar\load\mods\00040000001C8F00\romfs`

ชุดนี้มีไฟล์ LayeredFS ภาษาไทยเท่านั้น ไม่รวมเกมหรือ ROM
