ระบบแปะแพตช์ไทยออนไลน์ — เพจแปลเกมเก่า

ประมวลผลทั้งหมดในเบราว์เซอร์ของคุณเอง — ไฟล์ ISO ต้นฉบับไม่ถูกส่งขึ้นเซิร์ฟเวอร์

หน้านี้ต้องเปิดผ่านเว็บเซิร์ฟเวอร์จริง (http/https) ไม่ใช่เปิดไฟล์ตรงๆ (file://) เพราะต้องโหลดไฟล์แพตช์และไลบรารีถอดรหัสผ่าน fetch/CDN — ทดสอบในเครื่องด้วย python -m http.server แล้วเข้า http://localhost:8000, หรือโฮสต์จริงผ่าน GitHub Pages / Netlify / Cloudflare Pages ก็ได้
