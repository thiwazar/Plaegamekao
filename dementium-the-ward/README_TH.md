## วิธีใช้แพตช์

เลือก Apply patch ในเครื่องมือที่รองรับ xdelta/VCDIFF เลือกรอมต้นฉบับเป็น Source และไฟล์ .xdelta เป็น Patch แล้วบันทึก Output เป็นไฟล์ .nds ใหม่

ตัวอย่างคำสั่ง:

```text
xdelta3 -d -s "original.nds" "Dementium_The_Ward_Thai_v1.0.xdelta" "Dementium_The_Ward_Thai_v1.0.nds"
```

SHA-256 ของผลลัพธ์ที่ถูกต้อง: `2972241f8f34433dc704ec9ddb8c9781ab0c58592b643a60dc7de57b90fa6cef`
หากใช้ไฟล์รอม v1.0 ที่จัดไว้แล้ว ไม่ต้องลงแพตช์ซ้ำ
คืนค่าโดยเปิดรอมต้นฉบับที่เก็บไว้ แพตช์ไม่ต้องเขียนทับรอมต้นฉบับ
