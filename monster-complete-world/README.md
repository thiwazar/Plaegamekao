# Monster Complete World Thai v1.0

Browser patcher for the original Japanese SLPS 018.70 BIN. Uses the spacing-corrected v4 build. Source ROM stays on the device. Both source and output SHA-256 are verified. No full ROM is distributed.

Cold boot after patching; do not restore an older save state. Japanese naming grid, movie subtitles and title artwork remain unchanged. Full-game testing is not complete.
