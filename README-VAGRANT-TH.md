# เพิ่ม Vagrant Story ภาษาไทย V9 Preview

เพิ่มเกมในหมวด PS1 ของเว็บเดิม และคงรายการเกมก่อนหน้าไว้

ใช้ BIN ของ Vagrant Story USA ต้นฉบับ ขนาด 750,643,152 ไบต์เท่านั้น ไม่ใช่ ISO, CHD, ZIP หรือ BIN ที่เคยลงแพตช์แล้ว

SHA-256 ต้นฉบับ: `25221d7f8fdb2c4490af12d9e82f0e58bdd6acb43387f9082b3c5e79dfe090c0`

SHA-256 ผลลัพธ์: `75cd068b335723fe34448d4c1d22b6de5951552c4049df59dc5ec9609adb16ca`

## อัปเดตเว็บเดิม

อัปโหลดไฟล์ต่อไปนี้ที่ระดับเดียวกับ index.html เดิม โดยคงโครงสร้างโฟลเดอร์:

- index.html
- vagrant-config.mjs, vagrant-ui.mjs, vagrant-worker.mjs
- fontfix-vcdiff.mjs และ vendor/sha256.umd.min.js (ใช้ตัวอ่านร่วมกับชุด Dissidia เดิม)
- patches/Vagrant_Story_USA_Thai_Preview_V9.xdelta
- patches/Vagrant_Story_Thai_Preview_V9.cue
- covers/Vagrant_Story_USA.jpg

ต้องคง fontfix-*.mjs, vendor, รูปปก และแพทช์เกมเดิมไว้ ชุด ZIP เป็นชุดอัปเดตสำหรับเว็บที่มีอยู่ ไม่ใช่เว็บเต็ม ห้ามลบไฟล์เกมอื่นที่ไม่ได้แนบในชุดนี้

ไม่มี BIN/ISO ต้นฉบับหรือไฟล์เกมเต็มอยู่ในแพทช์ ไม่ต้องอัปโหลด ROM ขึ้นเว็บไซต์ และชุดนี้ยังไม่ได้เผยแพร่ขึ้น GitHub Pages

## ใช้งาน

เลือก PS1 > Vagrant Story > เลือก BIN ต้นฉบับ รอการตรวจ SHA-256 และแพทช์ จากนั้นดาวน์โหลด BIN และ CUE ไว้โฟลเดอร์เดียวกันโดยไม่เปลี่ยนชื่อ เปิดเกมผ่าน CUE

การประมวลผลทำในเบราว์เซอร์ ไม่ส่งไฟล์เกมขึ้นเว็บ และไม่แก้ต้นฉบับ ต้องเปิดผ่าน HTTPS หรือ localhost ไม่เปิด index.html แบบ file://

## ขอบเขต

V9 ยังเป็นรุ่นทดลอง ไม่ใช่ไทยครบทั้งเกม เพิ่มประโยคตกหล่น 10 ประโยคและหน้าบรรยาย 11 หน้า ใช้ฟอนต์ที่ผู้ใช้วาด ยังไม่ได้ทดสอบ V9 ในอีมูเลเตอร์

ทดสอบตัวจัดการงานและตัวถอดแพทช์ที่จัดส่งด้วย File/Blob ใน Node: ต้นฉบับจริงให้ผล SHA-256 ตรงกับ V9, ตรวจไฟล์ที่เป็น V9 อยู่แล้ว, ปฏิเสธขนาดผิด นามสกุลผิด แฮชผิด และแพทช์เสียหาย รายละเอียดใน VAGRANT-WEB-TEST.json การทดสอบนี้ไม่เท่ากับการเล่นเกมจริง
