## ใส่ในเว็บ

อัปโหลดเฉพาะ .xdelta และ manifest.json ไม่ต้องอัปโหลด ISO เกม
เว็บต้องมี decoder รองรับ VCDIFF/xdelta3 มาตรฐาน การเปลี่ยนนามสกุลไฟล์อย่างเดียวไม่ทำให้ decoder รูปแบบ QDELTA1, STP หรือแพตช์เฉพาะเกมรองรับไฟล์นี้
ตั้งชื่อดาวน์โหลดจาก manifest.outputName เช่น downloadLink.download = manifest.outputName
manifest.json เป็นข้อมูลกลาง ไม่ใช่ config ที่ยืนยันว่าเว็บปัจจุบันอ่านได้ทันที ต้องเชื่อม fields เข้ากับโค้ดเว็บก่อน
