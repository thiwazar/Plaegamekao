วิธีติดตั้ง
1. เตรียม ISO ต้นฉบับของคุณเองให้ตรงกับค่าเช็กซัมด้านบน
2. ใช้โปรแกรมที่รองรับ BPS เช่น Rom Patcher JS:
   https://www.marcrobledo.com/RomPatcher.js/
3. เลือก ISO ต้นฉบับ และ Ragnarok_Tactics_Thai_v1.0.bps แล้วใช้คำสั่ง Apply patch
4. ตั้งชื่อผลลัพธ์ Ragnarok_Tactics_TH_v1.0.iso แล้วเปิดใน PPSSPP
หากเว็บแพตช์ไม่ไหวกับไฟล์ขนาดใหญ่ ใช้ apply_patch.py แบบออฟไลน์ (ต้องมี Python 3):
   python apply_patch.py "original.iso" "Ragnarok_Tactics_TH_v1.0.iso"
ห้ามลงทับแพตช์ไทยรุ่นเก่า ให้เริ่มจาก ISO ต้นฉบับเสมอ
เริ่มเกมจาก ISO ใหม่ตามปกติ ไม่โหลด save state จากรุ่นเก่าเพื่อทดสอบข้อความใหม่

สิ่งที่ปรับในรุ่น 1.0
- ปรับขนาดฟอนต์ไทยและเพิ่มขอบเข้มให้เมนูอ่านชัดขึ้น
- แปลชื่ออาชีพ 14 อาชีพ ป้ายเพศ แบบเสียง และข้อความสร้างตัวละคร
- เพิ่มคำอธิบายอาชีพ คำสั่งต่อสู้บางส่วน และหน้าสอนเรื่องอาชีพสองหน้า
- ปรับคำอธิบายในหน้าตั้งค่า และจัดเมนูหลักให้อยู่กึ่งกลาง
- รวมงานแปลบทสนทนาและฟอนต์ที่มีอยู่ในฐานรุ่นล่าสุด

ขอบเขต: 1.0 คือหมายเลขรุ่น ไม่ได้หมายถึงแปลครบ 100%
ยังมีอังกฤษบางส่วน เช่น หัวข้อ Character Making เมนู/ค่าสถานะการต่อสู้
