Dissidia 012 Thai — Patch v1.0
เกม: DISSIDIA duodecim FINAL FANTASY (ยุโรป ภาษาอังกฤษ / ULES01505)

ชุดนี้มีเฉพาะแพตช์ ไม่รวม ISO เกมหรือโปรแกรมจำลอง
แปลข้อความในชุดที่สกัดไว้ครบ 14 story + 40 message batches (15,181 ข้อความที่มีเนื้อหา)
ภาพตัวอักษรและหน้าระบบบางส่วนยังเป็นอังกฤษ
ฟอนต์ไทยฝังใน ISO ผลลัพธ์แล้ว เปิด ISO ตามปกติได้ ไม่ต้องใช้ตัวเปิดเกม .cmd
ทดสอบเมนูไทยบน PPSSPP Windows 1.20.4 โดยใช้ฟอนต์ภายนอกเดิมแล้ว
ยังไม่ได้ยืนยันบนเครื่องพกพาหรือ PSP จริง

วิธีใช้
1. เตรียมไฟล์ ISO จากเกมของคุณเอง รุ่น ULES01505
2. ตรวจ SHA-256 ให้ตรงกับไฟล์ฐานด้านล่างก่อนใช้ แพตช์นี้ไม่รองรับไฟล์ที่มี hash อื่น
3. ดาวน์โหลด xdelta3 รุ่น 3.2.0 จาก https://github.com/jmacd/xdelta/releases
   แพตช์สร้างด้วยรุ่นนี้ รุ่นเก่าอาจอ่านรูปแบบแพตช์ไม่ได้
4. วาง xdelta3.exe, แพตช์ และ ISO ต้นฉบับในโฟลเดอร์เดียวกัน แล้วเรียก:
   xdelta3.exe -d -s "Dissidia_012_Original.iso" "Dissidia_012_Thai_v1.0.xdelta" "Dissidia_012_Thai.iso"
5. เปิด Dissidia_012_Thai.iso ใน PPSSPP ตามปกติ
หากเป็น CSO ที่บีบอัดจริง ให้แปลงเป็น ISO ก่อนตรวจ hash
อย่าแพตช์ทับไฟล์ต้นฉบับ และอย่าฝืนข้ามการตรวจ checksum

ไฟล์ฐานที่รองรับ
ขนาด: 1,741,168,640 bytes
SHA-256: 5877d20b328f45315251c6c605230e3a442ca0bffb51f54e9750e27329650e6c
ฐานนี้คืนทรัพยากรเมนูอังกฤษหนึ่งไฟล์จากไฟล์ที่สกัดไว้ ยังไม่ได้ตรวจเทียบ Redump
ยังไม่ได้ยืนยันว่าจะตรงกับ ISO ทุกแหล่งของรุ่นเดียวกัน
ISO ที่เคยแก้เมนูไว้ในโครงการไม่ตรงกับ hash นี้และใช้แพตช์ไม่ได้

ISO ไทยที่ได้
ขนาด: 1,751,234,560 bytes
SHA-256: 1f0e0fef812a4891e6ba06aef50c980e15d73a7e36b171095cb41bebaba93aa4
ทดสอบใช้แพตช์กับฐานที่รองรับแล้ว ผลลัพธ์ตรงกับ ISO ไทยทุกไบต์ตาม SHA-256

สำหรับนำขึ้นเว็บไซต์
แจก ZIP ชุดนี้ได้โดยไม่ต้องแนบ ISO เกม
แจ้งรุ่นเกม, hash ไฟล์ฐาน และข้อจำกัดการทดสอบตามข้อความข้างต้น
