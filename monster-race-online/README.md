# Monster Race Thai v1.0 online patch

This folder contains a browser-side patch page and a sparse binary patch for the Japanese PlayStation disc SLPM 861.43. The original BIN is checked by SHA-256 and remains on the user's device. The generated BIN is checked against its target SHA-256 before download; a matching CUE file is generated beside it.

Patch source SHA-256: `c30b46781ae99ab94679cfff3732bcf3cdb11432b65d791fda6ac392f605d714`

Thai target SHA-256: `65f49913eb33e39a102dad55ec3419059537010c2672ef2c1bdde40b11524612`

Integrity verification confirms the patch reconstructs the exact target BIN. The page must continue to identify the release as awaiting emulator boot/play testing until it has been tested in an emulator.
