# Muramasa Rebirth — Plaegamekao integration

เพิ่มการ์ด Muramasa และหมวด PS Vita ในหน้าเดิม พร้อมหน้าสร้างแพตช์ `muramasa/index.html` ใช้กับ PCSE00240 อัปเดต 1.06 รุ่นทดสอบ 0.1.0

## นำขึ้นเว็บ

1. สำรอง `index.html` เดิมก่อน
2. นำ `index.html` และโฟลเดอร์ `muramasa` จากชุดนี้วางในรากของ repository Plaegamekao ไม่ต้องแก้หรือลบไฟล์เกมอื่นบนเว็บ
3. Commit ไปยัง branch ที่เว็บไซต์ใช้เผยแพร่ แล้วรอ deployment ของเว็บเดิม
4. เปิดหน้าแรก เลือก PS Vita → Muramasa หรือเปิด `muramasa/index.html` ใต้ URL เว็บเดิม

ใช้ static hosting เดิมได้ ไม่ต้องมี API หรือเซิร์ฟเวอร์รับไฟล์เกม ทุก path เป็น relative จึงใช้ใต้ `/Plaegamekao/` บน GitHub Pages ได้ ต้องให้โฮสต์ส่ง `.js` เป็น JavaScript และเปิดผ่าน HTTPS หรือ localhost ไม่ใช้ file://

## ผู้เล่นใช้งาน

เลือก CPK ต้นฉบับทีละไฟล์: `NinPri.cpk` และ `NinPriPatch.cpk` เว็บตรวจขนาดและ SHA-256 ของต้นฉบับ แพตช์ และผลลัพธ์ก่อนให้ดาวน์โหลด ปิด Vita3K สำรอง CPK เดิมแล้วแทนผลลัพธ์ในตำแหน่งเกมที่อีมูเลเตอร์ใช้งานจริง ระวังไฟล์อัปเดตแยกใน ux0/patch ที่อาจถูกโหลดแทนไฟล์ใน app

ไฟล์เกมของผู้ใช้ไม่ถูกอัปโหลด ชุดเว็บแจกเฉพาะส่วนต่าง VCDIFF และเครื่องมือ ไม่รวม CPK เต็มหรือเซฟเกม ปุ่มกลับคลังเกมอยู่มุมซ้ายบน

## ข้อจำกัด

รุ่นทดสอบ: ยังมีภาพข้อความอังกฤษบางส่วน เช่น Yes/No และไม่ได้ยืนยันครบทุกฉากบน Android หรือ Vita จริง ใช้แพตช์เฉพาะที่มากับหน้านี้ ตัวถอด VCDIFF รองรับชุดคำสั่งที่ตัวสร้างแพตช์นี้ใช้ ไม่ใช่ตัวอ่าน xdelta ทั่วไปทุกแบบ

หากโทรศัพท์มีหน่วยความจำไม่พอ ให้สร้างบนคอมแล้วคัดลอก CPK ผลลัพธ์ไปโทรศัพท์ เก็บต้นฉบับไว้สำหรับย้อนกลับ
