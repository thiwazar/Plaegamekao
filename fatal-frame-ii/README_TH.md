# Fatal Frame II: Crimson Butterfly ภาษาไทย v1.0

แพตช์นี้ใช้กับ `Fatal Frame II (U) (Undub v1.0.2).iso` เท่านั้น ระบบบนเว็บไซต์จะตรวจขนาดและ SHA-256 ก่อนสร้าง ISO ภาษาไทย และจะไม่อัปโหลดไฟล์เกมของผู้ใช้ขึ้นเซิร์ฟเวอร์

- ขนาดต้นฉบับ: 3,332,839,424 ไบต์
- SHA-256 ต้นฉบับ: `233ba3b13aeb23b01c42586ab7ec8cb80effee866d3385642f630fcea2fc3034`
- ขนาดผลลัพธ์: 3,333,660,672 ไบต์
- SHA-256 ผลลัพธ์: `bbcfd3e9d1143d7a39ded57bd6e43c7b1607e52d640c93da7c38b37ca1622c5b`

รุ่นนี้รวมคำแปลข้อความเนื้อเรื่อง เมนู เอกสาร และเนื้อเพลงตอนจบ ใช้ฟอนต์ Noto Sans Thai และแก้ตำแหน่งสระกับวรรณยุกต์แล้ว ข้อมูลแพตช์แบ่งเป็นชิ้นส่วนขนาดเล็ก ส่วนข้อมูล ISO ที่ไม่เปลี่ยนจะอ้างอิงจากไฟล์ต้นฉบับบนเครื่องโดยตรงเพื่อไม่ต้องโหลด ISO หลายกิกะไบต์เข้า RAM

สถานะการตรวจสอบ: ตัวสร้าง ISO และ SHA-256 ของผลลัพธ์ผ่านการตรวจสอบแล้ว แต่ยังไม่ได้ทดสอบเล่นจบเกมบน PCSX2
