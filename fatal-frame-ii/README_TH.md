# Fatal Frame II: Crimson Butterfly ภาษาไทย v1.3

แพตช์นี้ใช้กับ `Fatal Frame II (U) (Undub v1.0.2).iso` เท่านั้น ระบบบนเว็บไซต์จะตรวจขนาดและ SHA-256 ก่อนสร้าง ISO ภาษาไทย และจะไม่อัปโหลดไฟล์เกมของผู้ใช้ขึ้นเซิร์ฟเวอร์

- ขนาดต้นฉบับ: 3,332,839,424 ไบต์
- SHA-256 ต้นฉบับ: `233ba3b13aeb23b01c42586ab7ec8cb80effee866d3385642f630fcea2fc3034`
- ขนาดผลลัพธ์: 3,334,328,320 ไบต์
- SHA-256 ผลลัพธ์: `415f36e5191f7aad3381b7acb8cbeacc7509764293ba134c0d8fd85c0d91f9c3`

v1.3 แก้พื้นหลังด้านขวาที่แหว่งจาก v1.2 และจัดโลโก้กับเครดิตกึ่งกลางภาพเต็ม 640 พิกเซล โดยรักษาชิ้นภาพเมนูและลิขสิทธิ์เดิม ตรวจภาพประกอบจากข้อมูล ISO แล้ว ยังไม่ได้ยืนยันภาพใน PCSX2

รุ่นนี้รวมคำแปลข้อความเนื้อเรื่อง เมนู เอกสาร และเนื้อเพลงตอนจบ ใช้ฟอนต์ Noto Sans Thai แก้ตำแหน่งสระกับวรรณยุกต์ และเพิ่มโลโก้หน้าไตเติล `เฟตัลเฟรม 2` พร้อมข้อความ `แปลโดย เพจแปลเกมเก่า` รุ่น v1.2 ลบเศษโลโก้ภาษาอังกฤษและเลข `II` เดิม พร้อมจัดโลโก้ไทยกับเครดิตไว้กึ่งกลาง ข้อมูลแพตช์แบ่งเป็นชิ้นส่วนขนาดเล็ก ส่วนข้อมูล ISO ที่ไม่เปลี่ยนจะอ้างอิงจากไฟล์ต้นฉบับบนเครื่องโดยตรงเพื่อไม่ต้องโหลด ISO หลายกิกะไบต์เข้า RAM

สถานะการตรวจสอบ: ตัวสร้าง ISO และ SHA-256 ของผลลัพธ์ผ่านการตรวจสอบแล้ว แต่ยังไม่ได้ทดสอบเล่นจบเกมบน PCSX2
