ใช้รอม USA ต้นฉบับแบบถอดรหัส ขนาด 4,294,967,296 ไบต์ (4 GiB) รหัสเกม 00040000000FC500 ระบบตรวจ SHA-256 ก่อนเริ่ม ไม่รองรับ .cia รอมตัดขนาด หรือรอมที่เคยแพตช์แล้ว

ดาวน์โหลดรอมภาษาไทย

แนะนำ Chrome หรือ Edge บนคอมพิวเตอร์ และพื้นที่ว่างอย่างน้อย 10 GB อย่าปิดหน้านี้ระหว่างทำงาน ข้อมูลแฮชและรุ่นแพตช์


เล่นบนเครื่อง 3DS จริงด้วย Luma
ใช้ชุด Luma แยกต่างหาก ไม่ต้องแพตช์รอม .3ds บนหน้านี้
ดาวน์โหลดชุด Luma
  1. สำรองเซฟและโฟลเดอร์ม็อดเดิมของเกมก่อนติดตั้ง
  2. แตกชุด Luma แล้วคัดลอกโฟลเดอร์ luma ลงราก SD โดยนำโฟลเดอร์ม็อดเก่าออกก่อน
  3. กด Select ค้างขณะเปิดเครื่อง เปิด Enable game patching แล้วบันทึก
  4. ใช้เกม USA รหัสตรงกัน เลือกภาษา English เพื่อโหลดข้อความชุดภาษาอังกฤษที่แปลไทยไว้

สถานะการทดสอบ
ตรวจไฟล์ build 003 และเทียบ 401 ตารางแล้ว ทดสอบ Azahar 2126.0: โหลดเซฟช่อง 2 กด Y เปิด Party Chat “การสร้างหมู่บ้านขึ้นมาใหม่” ที่ Norende Ravine – Trail อ่านจนจบและเดินต่อได้
ยังไม่ได้ยืนยันบนเครื่องจริง/Luma ฉากเรือที่เคยค้าง หรือการเล่นจบทั้งเกม ผลทดสอบเว็บและแฮชดาวน์โหลดแยกเก็บใน ผลทดสอบเว็บ และ รายการไฟล์
เมื่อใช้รอมที่แพตช์แล้วใน Azahar ให้ปิดม็อดเก่า เลือกภาษา English และโหลดเซฟปกติ
