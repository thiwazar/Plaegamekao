เกม USA / Title ID 00040000000FC500 / เลือกภาษา English

ติดตั้ง Luma
1. สำรองเซฟและโฟลเดอร์ SD:/luma/titles/00040000000FC500 เดิม
2. ย้ายม็อดเดิมออกก่อน เพื่อไม่ให้ไฟล์เก่าปะปน
3. แตก ZIP แล้วคัดลอกโฟลเดอร์ luma ลงราก SD
   เส้นทางที่ถูกต้อง: SD:/luma/titles/00040000000FC500/romfs/
4. กด SELECT ค้างขณะเปิดเครื่อง เปิด Enable game patching และบันทึก
5. ใช้เกมรหัสตรงกันและเลือกภาษา English จากนั้นโหลดเซฟปกติ
6. ย้อนกลับโดยนำโฟลเดอร์ของชุดนี้ออกแล้วคืนม็อดเดิม

ติดตั้งใน Azahar
เปิดโฟลเดอร์ Mods ของเกม แล้วคัดลอก romfs จากชุดนี้ลงไป
ปิดและเปิดเกมใหม่ก่อนทดสอบ ไม่ใช้ Save State จากแพตช์ต่างรุ่น
