1. แพตช์ออนไลน์
ใช้โฟลเดอร์ bravely-second ทั้งชุดบนเว็บ HTTP/HTTPS เช่น GitHub Pages
เปิด index.html ผ่านเว็บ เลือกรอมต้นฉบับ แล้วกดตรวจไฟล์และแปะแพตช์ เมื่อผ่านการตรวจผลลัพธ์จึงกดดาวน์โหลด
รอมถูกอ่านและประกอบในเบราว์เซอร์ ไม่อัปโหลดรอมไปยังเซิร์ฟเวอร์
ใช้ไฟล์ BravelySecond_Thai_build009.qgdelta กับหน้าแพตช์ที่แนบ รูปแบบ QGDELTA2 ไม่ใช่ xdelta และใช้กับตัวแพตช์ xdelta ทั่วไปไม่ได้
แนะนำ Chrome/Edge บนคอมพิวเตอร์และพื้นที่ว่าง 10 GB ไฟล์ขนาดใหญ่ยังไม่ได้ทดสอบบนมือถือ
ใน Azahar ให้ปิดม็อดเก่าของเกมเมื่อใช้รอมที่แพตช์แล้ว ตั้งภาษา English และเปิดจากเซฟปกติ ไม่ใช้ Save State ต่างรุ่น
ย้อนกลับโดยเปิดรอมต้นฉบับที่เก็บไว้

2. เครื่อง 3DS จริงที่ใช้ Luma3DS
ใช้ BravelySecond_Thai_build009_Luma.zip แยกจากการแพตช์ .3ds
สำรองเซฟและโฟลเดอร์ SD:/luma/titles/000400000017BA00 เดิมก่อนเปลี่ยน
นำโฟลเดอร์ม็อดเดิมของเกมออกจากตำแหน่งใช้งานก่อน แล้วแตก ZIP และคัดลอกโฟลเดอร์ luma ลงราก SD
ตำแหน่งที่ถูกต้อง: SD:/luma/titles/000400000017BA00/romfs/...
มี locale.txt ค่า USA EN เพื่อเลือกข้อความ Common_en ที่แปลไทยไว้
ปิดเครื่อง กด Select ค้างขณะเปิดเครื่อง เปิด Enable game patching แล้วกด Start บันทึก
เปิดเกม USA รหัสตรงกันจากตลับหรือเกมที่ติดตั้งอยู่ เครื่องต้องมี Luma3DS อยู่แล้ว
ไม่ได้ยืนยันความเข้ากันได้กับอัปเดตเกมหรือม็อดอื่น และยังไม่ได้ทดสอบเครื่องจริง
ย้อนกลับ: ปิดเครื่อง นำโฟลเดอร์ 000400000017BA00 ของชุดนี้ออกจาก luma/titles แล้วคืนโฟลเดอร์สำรองเดิม หากเดิมไม่มีม็อด ให้ปล่อยตำแหน่งนี้ว่าง
ไม่ต้องเปลี่ยน boot.firm หรือแก้ระบบเครื่องเพื่อใช้ชุดไฟล์นี้

3. ผลตรวจและข้อจำกัด
ตรวจรอมต้นฉบับกับไฟล์ภายใน 3,711 ไฟล์ ประกอบข้อมูลเดิมกลับแล้วทุก payload ตรงเดิม
อ่านชุดภาษาไทยจากรอมที่ประกอบเสร็จกลับได้ตรงไฟล์ที่ต้องการทั้งหมด ส่วนโปรแกรม ExeFS, ExHeader, logo, plain และพาร์ทิชันอื่นคงเดิม
ตรวจ SHA-256 ของโครงสร้าง IVFC ทุกระดับผ่าน และทดลองใช้ .qgdelta กลับได้แฮชตรงรอมเป้าหมาย
ผลทดสอบเบราว์เซอร์ดู web_test.json ที่แนบเมื่อทดสอบเสร็จ ผลตรวจไฟล์ไม่ใช่ผลทดสอบการเล่น
ยังไม่ได้ทดสอบเปิดเกมจากรอมใหม่นี้หรือเล่นบนเครื่อง 3DS จริง ไม่รับรองว่าอาการค้าง Aero/ฮาปี้/ก็อบลินหายแล้ว
ตัวข้อความใช้ build009 เดิม มีข้อจำกัดการจัดตำแหน่งวรรณยุกต์ตามบริบท และความกว้างบางช่องยังเป็นค่าประเมินออฟไลน์
คงข้อความญี่ปุ่น เครดิต และข้อมูลที่พิสูจน์ไม่ได้ตามต้นฉบับ ไม่ใช่การยืนยันว่าแปลครบทุกภาพและทุกข้อความ
